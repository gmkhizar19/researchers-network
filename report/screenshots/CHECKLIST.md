hand-edited numbers. This file records **what each image must prove** so that a
missing or stale screenshot is easy to spot.

## Regeneration

```powershell
# Figures (Neo4j + GDS needed for p1/p2; p3 needs only CSVs)
.\.venv\Scripts\python.exe -m analysis.p1_fragility
.\.venv\Scripts\python.exe -m analysis.p2_silos_linkpred
.\.venv\Scripts\python.exe -m analysis.p3_reviewers

# UI screenshots (two terminals)
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --port 8000
cd frontend; npm run dev
cd frontend; npm run screenshots
```

If a value in a screenshot changes, update the matching claim in `README.md` and
`docs/EXPLAIN.md` in the same commit. Stale screenshots are worse than none.
